# Portfolio — Theo Arnaud-Manchado

## Structure
- index.html — page d'accueil
- projets/*.html — une page par projet
- style.css — tout le style (les 2 couleurs sont en haut : --ink et --paper)
- main.js — filtres du portfolio + onglets du parcours
- img/ — tes images (ex. img/tropical-cove.jpg, img/photo.jpg)
- videos/ — vidéos courtes en boucle (< 100 Mo, idéalement < 10 Mo)
- assets/ — ton CV en PDF : assets/CV-Theo-Arnaud-Manchado.pdf

## À remplacer
Cherche les crochets [ ... ] et les commentaires <!-- Remplace par ... --> dans les fichiers.
- email : ton.email@exemple.fr (index.html + chaque page projet)
- liens LinkedIn / ArtStation / GitHub / Vimeo dans index.html

## Ajouter un projet
1. Copie un fichier de projets/ et renomme-le.
2. Ajoute sa carte dans index.html (bloc <a class="card" ...>).
3. data-tags = perso, ecole et/ou outils (pour les filtres).
4. Mets à jour les liens Précédent / Suivant.

## Mise en ligne (GitHub Pages)
Dépôt public nommé ton-pseudo.github.io → upload de tout le dossier → Settings > Pages > branche main, dossier / (root).
